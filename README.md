# Group-7

The Personal Diary Management System is developed using C programming language. This project allows users to manage a personal diary, allowing users to add, edit, delete, and search entries. It also uses file handling for data storage and encryption for privacy.

The features that are available in this diary management system are:
1. Password Protection: Set a password on the first run and log in before accessing the diary.
2. Add Entries: Create diary entries with an automatically generated date, title, and content.
3. View Entries: Display all saved diary entries.
4. Search Entries: Search by date or keywords in titles and content.
5. Edit Entries: Update an existing entry's title or content while keeping its original date.
6. Delete Entries: Delete selected entries after confirmation.
7. Change Password: Change the existing password after verifying it.
8. Basic Encryption: Apply XOR encryption to stored diary titles, content, and password data.
9. Input Handling: Use helper functions to handle user input and screen navigation.
10. Cross-Platform Screen Clearing: Support Windows and Linux/macOS terminal commands.

We used these header files in our code:
1. <stdio.h> - Standard input/ output
2. <stdlib.h> - Standard library
3. <string.h> - String handling
4. <time.h> - Date and time
5. <ctype.h> - Character handling
